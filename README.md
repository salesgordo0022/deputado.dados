# Grajaú 2026 – Votação para Deputado Estadual

Site estático com a votação de Ricardo Seidel (55123) em Grajaú (MA) no 1º turno de 2026 e um painel com todos os candidatos a Deputado Estadual votados no município.

- `index.html` – página completa (dados embutidos)
- `ricardo-seidel.jpg` – foto do candidato
- `vercel.json` – configuração da Vercel

Fontes: boletins de urna e resultados do TSE (resultados.tse.jus.br) e cadastro "Eleitorado por local de votação 2026" (dadosabertos.tse.jus.br).

Deploy: importe este repositório na Vercel (Add New → Project → Import Git Repository). Não precisa de build.
